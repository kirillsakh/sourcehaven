# Research: storage options (verified 2026-11-19)

[V] = verified against the linked official source; [U] = unverified, confirm before relying on it.

## PostgreSQL + pgvector
- pgvector 0.8.7 (2026-10-01) is current; Docker tags `pgvector/pgvector:0.8.7-pg18` (also trixie/bookworm variants). PG19 docs exist but pgvector images do not list PG19 yet. [V]
- Approximate indexes (HNSW/IVFFlat) apply WHERE filters after the index scan. Iterative scans (`hnsw.iterative_scan`, since 0.8.0) help, but highly selective filters can still exhaust `hnsw.max_scan_tuples` (default 20k) and under-return. [V]
- For small, selective scopes the docs recommend a B-tree index on the filter column: exact search with perfect recall. A per-session corpus of a few thousand chunks fits this. (Not benchmarked.)
- Index dimension limits: `vector` up to 2,000 dims, `halfvec` up to 4,000. [V]
- Full-text search: a built-in Snowball `english` configuration covers English stemming. [V]
- Alternatives: ParadeDB pg_search (AGPL-3.0), VectorChord-bm25 (AGPLv3/ELv2, English-tested only). [V]
- `langchain-postgres` 0.0.19 (2026-10-06); `PGVector` deprecated in favour of `PGVectorStore` with `HybridSearchConfig`. [V]
- `llama-index-vector-stores-postgres` 0.10.0 depends on psycopg2-binary (cp314 wheels exist). [V]

## Qdrant
- v1.20.2 current. Payload-based multitenancy with `is_tenant` keyword index; strongest filtered HNSW; hybrid (sparse, BM25, RRF/DBSF, multivector). [V]
- Still requires Postgres for relational metadata; no cross-store transactions; snapshots not coordinated with Postgres.

## Chroma (server mode)
- chromadb 1.5.9. Single-node positioned for small to medium workloads; thin auth (token/basic) [U]; its own cookbook calls naive per-user tenancy "probably not suited for production". [V] Weakest fit for a public multi-tenant app.

## MongoDB Community + mongot
- $vectorSearch in Community Edition GA 2026-06-30 via separate SSPL-licensed `mongot`; requires replica set + keyfile; current docs require MongoDB 8.3+. [V] Heavier to operate; young self-hosted feature.
